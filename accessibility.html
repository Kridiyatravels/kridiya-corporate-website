Accessibility

Accessibility and assistance.

If you have difficulty using this website, the corporate desk can help with your enquiry.

Using the site

The public navigation opens with buttons that can be used from a keyboard. Escape closes an open menu. Forms provide labelled fields and validation feedback, and reduced-motion preferences are respected.

Help with a task

If a page or control prevents you from completing a task, contact corporate@kridiyatravel.com or call +971 50 941 3873. Tell us the page, the task and the difficulty. We can help coordinate your request through the desk.

Travel assistance needs

Tell the desk about assistance requirements while planning the journey so the relevant arrangements can be checked with suppliers. Avoid sharing medical records in a public enquiry.
